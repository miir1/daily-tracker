# 데일리 체크 트래커

개인용 하루 체크 웹앱. 명세서: `데일리 체크 트래커 개발 명세서.docx` (2026-10-11).
완료: 명세서 **1~7단계 전부** (오늘 체크, 백업, PWA, 운동 카드·증량, 주간 점검, 달력·그래프, 설정) + 예상 시간표, 비공개 항목.

## 파일 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 뼈대 (상단 날짜·완료율, 카드들, 하단 탭 4개) |
| `style.css` | 디자인. 모바일 360px 기준, 터치 영역 44px, 다크 모드 자동 |
| `items.json` | 체크 항목·숫자 항목·체중 요일 목록. **항목을 바꾸려면 이 파일만 고치면 됨** |
| `js/date.js` | 서울 기준 날짜 계산 (오늘, 날짜 더하기, 요일) |
| `js/db.js` | IndexedDB 저장·불러오기 (브라우저 안에만 저장, 외부 전송 없음) |
| `js/app.js` | 시작점. 오늘 탭 그리기, 탭 전환, 백업·비공개 항목 연결 |
| `js/core.js` | 공통 로직: 항목 목록 만들기(공개+비공개+설정 편집), 하루 기록 저장, 완료율, 주 계산 |
| `js/workout.js` | 운동 카드, 증량 규칙(2회 연속 완료 → +2회/+5초), 걷기 증량 |
| `js/weekly.js` | 주간 점검 탭: 지표 6개, 쿨다운 아이디어, 개선 항목 |
| `js/stats.js` | 기록·통계 탭: 월 달력, 체중·수면·게임 그래프, 항목별 준수율 |
| `js/settings.js` | 설정 탭: 항목 추가·수정·숨김·순서, 운동 목표 조정, 요일·화면 모드 |
| `js/backup.js` | JSON 내보내기·가져오기(병합), CSV 내보내기, 백업 알림 판단 |
| `private_items.json` | **비공개** 약물 항목. git 제외(GitHub에 안 올라감). 폰 설정 탭 → '비공개 항목 불러오기'로 넣음 |
| `manifest.json`, `icons/` | 홈 화면 아이콘·앱 이름 (PWA) |
| `sw.js` | 서비스 워커 — 앱 파일을 폰에 보관해 오프라인에서도 열리게 함 |
| `serve.bat` | PC에서 로컬 테스트용 실행 |
| `deploy.bat` | 커밋된 내용을 GitHub Pages로 올림 |

## 실행

**폰 (PC 꺼도 됨):** https://miir1.github.io/daily-tracker/ → 크롬 메뉴 → "홈 화면에 추가".
코드를 고친 뒤에는 C:\dev 에서 커밋 → `deploy.bat` 실행 → 1~2분 뒤 반영.

**PC 로컬 테스트:** `serve.bat` 더블클릭 → http://localhost:8510
(index.html을 직접 더블클릭하면 items.json을 못 읽음.)

## 알아둘 점

- 기록은 **그 브라우저 안**에만 있음. 기기 간 옮기기·백업은 설정 탭의 JSON 내보내기/가져오기로.
- 주소가 바뀌면 다른 저장소로 취급됨 → 폰에서는 항상 위 GitHub Pages 주소만 사용.
- GitHub 저장소(miir1/daily-tracker)는 공개. 코드만 있고 개인 기록은 없음.
- 체중 입력칸은 `items.json`의 `weightDays`(기본: 일요일)에만 보임.
- 백업 파일(`*.json`, `*.csv`)은 이 폴더에 두더라도 `.gitignore`로 커밋 제외됨 (items.json만 예외).
